## A. PETUNJUK PENGISIAN

Kuesioner ini bertujuan untuk mengumpulkan penilaian Bapak/Ibu Guru terhadap kualitas Knowledge Graph (KG) yang dibangun dari buku teks Kurikulum Merdeka. Knowledge Graph adalah representasi terstruktur dari konsep-konsep pembelajaran beserta hubungan antar-konsep.

**Skala Penilaian (Likert 5 poin):**
| Nilai | Keterangan          |
|-------|---------------------|
| 1     | Sangat Tidak Setuju / Sangat Tidak Tepat |
| 2     | Tidak Setuju / Tidak Tepat    |
| 3     | Netral / Cukup                |
| 4     | Setuju / Tepat                |
| 5     | Sangat Setuju / Sangat Tepat  |

**Estimasi waktu pengisian:** 20-25 menit
