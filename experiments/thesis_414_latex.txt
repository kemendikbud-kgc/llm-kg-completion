1. COSINE SIMILARITY (main formula)

$$\text{sim}(\mathbf{a}, \mathbf{b}) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \times \|\mathbf{b}\|} = \frac{\displaystyle\sum_{i=1}^{d} a_i \, b_i}{\sqrt{\displaystyle\sum_{i=1}^{d} a_i^2} \;\times\; \sqrt{\displaystyle\sum_{i=1}^{d} b_i^2}}$$


2. SIMILARITY RANGE

$$\text{sim}(\mathbf{a}, \mathbf{b}) \in [-1, \; 1]$$


3. CANDIDATE SET (threshold filter)

$$\text{candidates}(q) = \left\{ \, c \in \mathcal{C} \;\middle|\; \text{sim}(\mathbf{e}_q, \, \mathbf{e}_c) \geq \tau \, \right\}$$


4. THRESHOLD VALUES

Intra-buku:
$$\tau = 0{.}80, \quad k = 10$$

Lintas-buku:
$$\tau = 0{.}75, \quad k = 5$$


5. COMPLEXITY REDUCTION (exact pairwise vs HNSW)

$$O(n^2) \xrightarrow{\text{HNSW}} O(n \log n)$$


6. HNSW SEARCH COMPLEXITY (per query)

$$O(\log n) \quad \text{per query node}$$


7. BRUTE-FORCE COMPLEXITY (for contrast)

$$O(n) \quad \text{per query node (linear scan)}$$


8. TOTAL PAIRWISE (brute-force all-pairs)

$$\binom{n}{2} = \frac{n(n-1)}{2} \approx O(n^2)$$


9. EMBEDDING DIMENSIONALITY

$$\mathbf{e}_c \in \mathbb{R}^{d}, \quad d = 3072$$


10. HNSW DEFAULT PARAMETERS

$$M = 16, \quad \text{ef\_construction} = 100$$


11. CONFIDENCE SCORE RANGE (LLM classifier output)

$$\text{confidence} \in [0, \; 1]$$


12. DEDUPLICATION (pair normalization)

$$\text{key}(A, B) = \text{sorted}(A, B) \implies (A, B) \equiv (B, A)$$
